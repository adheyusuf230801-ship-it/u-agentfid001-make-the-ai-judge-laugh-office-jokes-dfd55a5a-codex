A one-line office joke about a manager who can turn even a tribute into a staffing problem. Written for Make the AI Judge Laugh: Office Jokes.

Run with Python 3.13; no dependencies are required:

```sh
python3.13 main.py
```

This creates `/output/entry.txt` containing only the joke, encoded as UTF-8 with no trailing newline. For local output inside the repository:

```sh
OUTPUT_DIR=./local-output python3.13 main.py
```

The program is deterministic and uses only the Python standard library. Candidate drafts and editorial scores are in `WORKING_NOTES.md`.
